# پیش‌نمایش زنده‌ی افزونه Shoper

هدف این پوشه: **تست عملکرد واقعی افزونه قبل از نصب روی سایت**.

## اجرا

```bash
npm install          # فقط بار اول (jsdom برای تست، jquery برای رابط)
npm run preview      # سرور روی http://localhost:3000
```

سپس در مرورگر باز کنید: <http://localhost:3000>

## این پیش‌نمایش «واقعی» است، نه ماکت

| بخش | چه چیزی اجرا می‌شود |
|---|---|
| رابط کاربری | فایل‌های **واقعی** افزونه: `admin/js/admin.js` و `admin/css/admin.css` (از مسیر `/plugin/…` سرو می‌شوند) |
| لایه‌ی AJAX | اندپوینت `admin-ajax.php` وردپرس شبیه‌سازی می‌شود با همان اکشن‌ها: `shoper_suggest`، `shoper_search`، `shoper_preview`، `shoper_create` |
| منطق سرور | `preview/server/torob-logic.js` — آینه‌ی دقیق کلاس‌های PHP افزونه |
| داده | API واقعی ترب، یا پاسخ‌های **واقعیِ ضبط‌شده** در `preview/fixtures/` |

> ⚠️ چون `admin.js` واقعی اجرا می‌شود، هر باگی در رابط کاربری افزونه در همین
> پیش‌نمایش هم ظاهر می‌شود. این دقیقاً هدف است.

## سه حالت منبع داده

در نوار بالای صفحه:

- **خودکار** (پیش‌فرض) — اول API زنده‌ی ترب را امتحان می‌کند؛ اگر شبکه در دسترس نبود
  خودکار روی داده‌ی ضبط‌شده برمی‌گردد و این را با برچسب اعلام می‌کند.
- **فقط زنده** — همیشه به `api.torob.com` وصل می‌شود. اگر شبکه نبود خطا می‌دهد.
- **داده‌ی ضبط‌شده** — بدون تماس با اینترنت، از `preview/fixtures/` می‌خواند.

هر نتیجه یک برچسب دارد: 🟢 «داده‌ی زنده از ترب» یا 🟡 «داده‌ی واقعی ضبط‌شده».

## داده‌های ضبط‌شده

فایل‌های `preview/fixtures/` **پاسخ‌های واقعی** `api.torob.com` هستند
(ضبط‌شده در ۲۰۲۶-۰۸-۱۶) نه داده‌ی ساختگی:

| فایل | محتوا |
|---|---|
| `search-samsung.json` | ۶ نتیجه‌ی واقعی جستجو با گالری و قیمت |
| `details-9bcf3364.json` | S26 Ultra — ۴۰ مشخصه‌ی فنی در ۶ گروه، ۵ فروشنده |
| `details-3f6b636a.json` | X-Inova Mini — محصول کم‌فروشنده، ۳ فروشنده |

## تست خودکار

```bash
npm test
```

کل جریان کاربر را در یک DOM واقعی (jsdom) اجرا می‌کند:

```
تایپ «سام» → نوار کشویی پیشنهاد → ناوبری با کیبورد
      → انتخاب → پیش‌نمایش محصول → ساخت محصول → خروجی ووکامرس
```

۲۹ بررسی، شامل: باز شدن نوار پیشنهاد، هایلایت عبارت تایپ‌شده، رندر گالری،
جدول فروشندگان بررسی‌شده، تولید ویژگی‌ها، SKU و نبود خطای جاوااسکریپت.

## چه چیزی شبیه‌سازی است؟

فقط **نوشتن در دیتابیس**. چون اینجا وردپرس/ووکامرسی نصب نیست، دکمه‌ی «ساخت محصول»
محصول واقعی نمی‌سازد؛ به‌جایش **دقیقاً همان چیزی که در سایت شما نوشته می‌شود** را
در تب‌های عمومی / ویژگی‌ها / تصاویر / توضیحات / متا نشان می‌دهد.

تصاویر هم در سایت واقعی با `media_sideload_image` در **کتابخانه‌ی رسانه** ذخیره
می‌شوند؛ در پیش‌نمایش فقط لیست تصاویری که دانلود خواهند شد نمایش داده می‌شود.

## نکته درباره‌ی محیط sandbox

اگر پیام 🟡 دیدید یعنی محیط اجرای فعلی به اینترنت دسترسی ندارد — این محدودیت
sandbox است، نه افزونه. API ترب با تست زنده تأیید شده است و روی هاست شما
(به‌خصوص هاست ایران) بدون مشکل کار می‌کند.
