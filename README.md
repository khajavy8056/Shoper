# Shoper Studio

سازنده هوشمند محصول ووکامرس — طراحی و توسعه: **خواجوی**.

**نسخه ۱.۵.۱:** بازنویسی هوشمند با سرویس‌های تست‌شده (Pollinations ناشناس + LLM7 به‌روز). Hugging Face بدون توکن عمومی کار نمی‌کند. نصب: `dist/shoper-torob-importer-1.5.1.zip`.

افزونه‌ی ووکامرس که با نوشتن **بخشی از نام محصول**، اطلاعات کامل آن را از
[ترب](https://torob.com) می‌گیرد و یک محصول کامل می‌سازد: نام، توضیحات،
گالری تصاویر و همه‌ی مشخصات فنی به‌صورت **ویژگی‌های مجزا**.

---

## قابلیت‌های اصلی

### ۱. نوار کشویی پیشنهاد نام

لازم نیست نام کامل محصول را بدانید. کافی است بنویسید «سام» یا «s26» تا
نام‌های کامل زیر فیلد پیشنهاد شوند — با تصویر، قیمت و تعداد فروشگاه.

```
┌──────────────────────────────────────────────┐
│ سام|                                    🔍  │
├──────────────────────────────────────────────┤
│ 📱 گوشی سامسونگ A26 5G | حافظه 256 رم ۸   │
│    Samsung Galaxy A26 • در ۱۲۱ فروشگاه      │
│                          از ۶۵٫۰۰۰٫۰۰۰ تومان │
│ 📱 گوشی سامسونگ S26 Ultra 5G | ۲۵۶ / ۱۲    │
│    Samsung Galaxy S26 • در ۹۶ فروشگاه       │
└──────────────────────────────────────────────┘
```

ناوبری با ↑ ↓ و انتخاب با Enter. عبارت تایپ‌شده هایلایت می‌شود.

### ۲. بررسی چند فروشنده (نه همه)

یک محصول ممکن است ۱۵۰ فروشنده داشته باشد؛ بررسی همه هم کند است و هم بی‌فایده.
Shoper فقط **چند فروشنده‌ی برتر** را بررسی می‌کند و اطلاعاتشان را تجمیع می‌کند:

- تعداد فروشنده: قابل تنظیم (پیش‌فرض ۳)
- معیار انتخاب: **معتبرترین** (پیش‌فرض) / ارزان‌ترین / ترکیبی
- آگهی‌های تبلیغاتی (`is_adv`) در رتبه‌بندی جریمه می‌شوند تا نتیجه طبیعی بماند

از میان آن‌ها استخراج می‌شود: قیمت، محدوده‌ی قیمت بازار، گارانتی،
شرایط ارسال و ویژگی‌های اعلام‌شده‌ی کالا (پلمپ شرکتی، رجیستر شده و …).

### ۳. مشخصات فنی به‌صورت ویژگی

هر مشخصه (پردازنده، حافظه، دوربین، وزن و …) یک **ویژگی مستقل** در تب
«ویژگی‌ها»ی محصول می‌شود. برای یک گوشی معمولاً **۴۰ مشخصه در ۶ گروه**.
قبل از ساخت می‌توانید تیک هرکدام را بردارید.

### ۴. نوار مراحل + بازنویسی هوشمند + نظارت

بعد از انتخاب محصول، فرایند در **۴ مرحله** است:

1. **دریافت اطلاعات** — نام، مشخصات دانه‌دانه، قیمت و تیک ویژگی‌ها.
2. **انتخاب تصاویر** — نگه‌داشتن تصویر + انتخاب تصویر اصلی.
3. **بازنویسی هوشمند** — معرفی، تحلیل کارشناسی، بررسی نقاط قوت و مخاطب هدف.
4. **نظارت و سئو** — شما متن را می‌بینید، ویرایش می‌کنید و بعد محصول ساخته می‌شود.

چند سرویس رایگان عمومی به‌صورت گردشی صدا زده می‌شوند تا سقف ساعتی یکی‌شان کار را نخواباند. کلید پولی داخل افزونه نیست (در مخزن عمومی فوراً دزدیده می‌شود). اگر سرویس‌ها قطع باشند، **استودیوی نویسندگی خواجوی** متن کامل را از همان مشخصات واقعی می‌نویسد.

### ۵. تصاویر با نام محصول + شماره

گالری کامل (۶ تا ۷ تصویر) در **کتابخانه‌ی رسانه‌ی سایت شما** ذخیره می‌شود — نه
لینک خارجی. کاربر تعیین می‌کند کدام تصاویر نگه داشته شوند و کدام‌یک **تصویر
اصلی** باشد. فایل‌ها با نام **`{نام محصول}-{شماره}`** ذخیره می‌شوند (مثل
`گوشی-سامسونگ-1.webp`).

### ۶. سئو و برچسب

عنوان سئو، توضیح متا و برچسب‌ها به‌صورت خودکار از نام و مشخصات محصول ساخته
می‌شوند (قابل ویرایش قبل از ساخت). برچسب‌ها در `product_tag` ثبت و متادیتای
سئو ذخیره می‌شود؛ اگر Yoast نصب باشد متادیتای آن هم پر می‌شود.

## پیش‌نمایش زنده — تست قبل از نصب

قبل از اینکه افزونه را روی سایت ببرید، می‌توانید عملکرد واقعی‌اش را تست کنید:

```bash
npm install
npm run preview      # http://localhost:3000
```

پیش‌نمایش، **فایل‌های واقعی افزونه** (`admin/js/admin.js` و `admin/css/admin.css`)
را اجرا می‌کند و اندپوینت `admin-ajax.php` وردپرس را شبیه‌سازی می‌کند — پس چیزی
که می‌بینید دقیقاً همان چیزی است که در پیشخوان وردپرس اجرا می‌شود.

سه حالت منبع داده دارد: **خودکار** / **فقط زنده** / **داده‌ی ضبط‌شده**.

تست خودکار کل جریان کاربر:

```bash
npm test             # ۲۹ بررسی روی DOM واقعی با jsdom
```

جزئیات بیشتر: [`preview/README.md`](preview/README.md)

## نصب روی سایت

1. پوشه‌ی `shoper-torob-importer` را در `wp-content/plugins/` آپلود کنید.
2. افزونه را فعال کنید (نیازمند ووکامرس).
3. از منوی **ووکامرس ← 🛒 Shoper (از ترب)** استفاده کنید.

همچنین در صفحه‌ی افزودن/ویرایش محصول یک متاباکس اضافه می‌شود تا محصول موجود
را مستقیماً از ترب پر کنید.
